# Automodelle

Base visual para un archivo histórico de marcas y modelos de automóviles. Esta primera versión es estática, responsive y accesible, con una portada, exploración conceptual y línea temporal listas para conectar al catálogo en la siguiente fase.

## Tecnología

- HTML para la estructura.
- CSS para el diseño responsive y las animaciones.
- JavaScript para las interacciones.

## Estructura

```text
Automodelle/
├── index.html
├── assets/
│   ├── css/styles.css
│   ├── js/script.js
│   └── images/
└── README.md
```

El proyecto no depende de un sistema de compilación: cualquier alojamiento de páginas estáticas puede servir directamente esta carpeta.
